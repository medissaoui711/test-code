# 🚀 Deployment Guide

TestPilot is a modern React application built with Vite. It is designed to be easily deployable to any static hosting provider or containerized environment.

## Build for Production

To generate a production-ready build:

```bash
npm run build
```

This will create a `dist` directory containing the optimized, minified static assets.

## Deployment Options

### 1. Vercel

The repository already includes a `vercel.json` file configured for SPA routing.

1. Connect your GitHub repository to Vercel.
2. Vercel will automatically detect it as a Vite project.
3. The build command (`npm run build`) and output directory (`dist`) will be configured automatically.
4. Deploy!

### 2. Cloudflare Pages

The repository includes a `public/_redirects` file to handle SPA routing in Cloudflare Pages.

1. Connect your GitHub repository to Cloudflare Pages.
2. Select **Vite** as the framework preset (or manually set build command to `npm run build` and output to `dist`).
3. Deploy!

### 3. Netlify

Netlify also uses the `public/_redirects` file (same format as Cloudflare Pages) for SPA routing.

1. Connect your GitHub repository to Netlify.
2. It will automatically detect Vite and set the build settings.
3. Deploy!

### 2. Docker / Cloud Run (Containerized)

TestPilot can be served using an Nginx or Node.js static server container.

**Example Dockerfile (Nginx):**
```dockerfile
# Build Stage
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Production Stage
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
# Add custom nginx.conf if SPA routing (index.html fallback) is required
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

**Build and Run:**
```bash
docker build -t testpilot-web .
docker run -p 8080:80 testpilot-web
```

### 3. Server-Side Environment Variables

While TestPilot is currently an anonymous-first SPA, if you implement backend API routes in the future, ensure the following constraints:

- Port 3000 is required for internal dev servers.
- Define any backend variables in a `.env` file based on `.env.example`.
- Ensure CORS policies allow requests from the domain where the static frontend is hosted.

## Performance Considerations

- **Caching:** Ensure your CDN aggressively caches static assets (JS, CSS, images) with cache-bursting hashes generated by Vite.
- **Compression:** Enable Gzip or Brotli compression on your web server.
- **Data Privacy:** Because TestPilot relies on `localStorage` for session isolation, ensure the application is served over HTTPS to protect against Man-In-The-Middle (MITM) attacks and ensure secure context APIs operate correctly.
